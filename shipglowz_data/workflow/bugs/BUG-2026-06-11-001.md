# Bug Record: BUG-2026-06-11-001

## Summary

- Title: WebView quick-add to shopping list fails without user alert
- Current status: `fix-attempted`
- Severity: `high`
- Owner: codex
- Next command: `/107-sg-test --retest BUG-2026-06-11-001`

## Reproduction

- Preconditions:
  - Android Tauri WebView session is open.
  - At least one shopping list exists and is synced to the native bottom-bar menu.
- Steps:
  1. Open a Temu product page inside a shopping session.
  2. Use the native WebView bottom-bar menu action `Ajouter à <liste>`.
  3. Return to the list.

## Expected Behavior

- If the current WebView page is a valid Temu product page, the app adds the product to the chosen list and shows a clear success notification.
- If the action cannot complete, the app shows a clear failure notification with a recovery path.

## Observed Behavior

- The operator reports that adding a product to a list via WebView currently does not work.
- The UI does not show an alert that the add failed.

## Evidence

- `app/src/ui/temu-shell/App.vue` handles `temu-webview-capture-requested`, but quick-add action branches call async list mutation helpers without a top-level failure guard.
- `app/src-tauri/plugins/android-temu-webview/android/src/main/java/com/temushoppinglists/temuwebview/TemuWebViewPlugin.kt` shows native Toast text "Ajout en cours" before Vue confirms success.
