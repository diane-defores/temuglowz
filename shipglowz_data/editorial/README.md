# TemuGlowz Editorial Governance

This corpus governs public claims, page intent, editorial updates, and public-content follow-up for the TemuGlowz site.

Read `content-map.md` first, then the page intent map, claim register, and editorial update gate before changing public copy or product-guide data.

## Trust posture

- TemuGlowz is independent and does not claim Temu approval or partnership before written confirmation.
- Published selections are curation, not hands-on testing, unless a page links to documented test evidence.
- Product price, availability, seller status, delivery and suitability must be treated as volatile or unverified unless evidence says otherwise.
- Affiliate disclosure must be understandable and placed near the recommendation/CTA it qualifies.

## Maintenance Rule

Update this index whenever a public surface, claim policy, or editorial owner changes.
